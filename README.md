🛍️ Modern E-Commerce Platform

A responsive, feature-rich web application built to deliver a seamless online shopping experience. This project features dynamic product browsing, shopping cart management, user authentication, and an intuitive checkout flow.

🌟 Key Features

Responsive UI/UX: Mobile-first, adaptive interface optimized across desktop, tablet, and mobile screens.

Product Catalog & Filtering: Browse items by category, search by keywords, and filter/sort by price and popularity.

Cart & Wishlist Management: Real-time quantity adjustments, subtotal/total calculations, and item persistence.

Secure Authentication: User registration, login, session handling, and profile dashboard.

Checkout & Order Flow: Streamlined checkout process with form validation, address management, and order summary.

Clean Architecture: Modular code structure separating assets, components/templates, and application logic.

🚀 Getting Started

Follow these steps to get a local copy up and running.

Prerequisites

A modern web browser (Chrome, Edge, Firefox, or Safari)

Optional: Node.js or Python for running a local development server.

Installation & Setup

Clone the repository:

git clone https://github.com/RS-Priyanshu/E-Commerce-website.git
cd E-Commerce-website

Run locally:

Method 1 (Direct): Open index.html directly in your web browser.

Method 2 (Live Server / Python HTTP Server):

# Using Python 3 built-in HTTP server:
python -m http.server 8000
